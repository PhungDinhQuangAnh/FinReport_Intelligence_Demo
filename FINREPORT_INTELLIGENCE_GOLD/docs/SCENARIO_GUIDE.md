# What-if / Scenario Guide

Tab What-if cho phép thay đổi giả định của một company-year:

- Revenue %
- COGS %
- CFO %
- Accounts Receivable %
- Inventory %
- Short-term Debt %
- Long-term Debt %
- Interest Expense %

Hệ thống tính lại Gross Profit, Operating Profit, PBT, Tax, Net Income và một số ratio quan trọng. Selling Expense, Admin Expense và D&A được giữ cố định trong mô phỏng hiện tại.

`scenario_risk_proxy` chỉ dùng để so sánh hướng biến động của kịch bản với base case. Nó không phải xác suất và không thay thế pipeline Gold đầy đủ.
